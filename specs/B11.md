# B11 Low-data and device hardening

Source: ATLAS V1 Build Guide, Claude Code pack tab, section 4. Exported 24 November 2026 in session S00.

```text
Read CLAUDE.md. This is step B11. Plan first.
1. "Download this topic" button that downloads every video for the topic at 360p, with progress and the total size shown before starting.
2. Play videos only from local storage once downloaded. Choose 480p only if the pupil is on Wi-Fi and the phone has space.
3. Queue answers and AI calls made offline; send them when the network returns; never lose an answer.
4. Measure and log data used per topic.
5. Replace every technical error with a calm plain message and a retry button.
6. Check performance on the slowest test phone: cold start, screen changes, video start time. Fix anything slower than 4 seconds.
Done when: the whole topic runs with only AI checks needing network, and no screen shows a raw error.
```
