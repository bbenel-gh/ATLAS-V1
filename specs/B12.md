# B12 Photo of handwriting (only if every earlier step is done)

Source: ATLAS V1 Build Guide, Claude Code pack tab, section 4. Exported 24 November 2026 in session S00.

```text
Read CLAUDE.md. This is step B12. Plan first.
1. Add a camera button next to the answer box. Take one photo, compress it, send it to ai-read-handwriting.
2. Show the text that was read in the answer box. The pupil must confirm or edit it before it is checked.
3. If reading fails, keep the photo out of storage and ask the pupil to type instead.
4. Delete the photo from the phone and the server after the text is confirmed.
Done when: 10 real handwritten answers are read correctly or corrected by the pupil, and no photos remain stored.
```
