# B7 AI hardening

Source: ATLAS V1 Build Guide, Claude Code pack tab, section 4. Exported 24 November 2026 in session S00.

```text
Read CLAUDE.md. This is step B7: hardening the four AI Edge Functions. Plan first.
1. Each function: build the request from the prompt template in specs/ai-prompts.md, call the Claude API with the model named there, parse the output with zod.
2. Invalid JSON or a schema failure: retry once with the same input. Second failure: return { fallback: true }. The app then offers tap options.
3. Time limit 20 seconds per call. On timeout return { fallback: true }.
4. Per-pupil cap: at most 120 AI calls per day across all jobs. Over the cap: { fallback: true } and a log line.
5. Log every call in ai_calls: job, model, pupil_id, input, output, ok, latency.
6. Any verdict of "unsure" creates a borderline flag for admin review.
7. Any safeguarding = true creates a safeguarding flag and sends an email or SMS alert to the address in the SAFEGUARDING_ALERT secret.
8. Never include the pupil's display name in any request.
Done when: unit tests cover bad JSON, timeout, cap and safeguarding; switching the network off mid-segment never traps a pupil.
```
