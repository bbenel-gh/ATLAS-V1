# B9 Mastery and re-check

Source: ATLAS V1 Build Guide, Claude Code pack tab, section 4. Exported 24 November 2026 in session S00.

```text
Read CLAUDE.md and specs/framework.md (Stage 8). This is step B9. Plan first, domain tests first.
Domain: mastery.ts decides mastery from exam score (at least 80%) and segment_status (no segment left at 3 failed tries).
1. On mastery: a short, calm celebration screen, the next topic shown as the top recommendation, mastery row saved with recheck_due = today + 3 days.
2. When recheck_due has passed, the next time the pupil opens the app, serve the 3 re-check questions before anything else (with an option to do it later today).
3. Pass: mastery confirmed. Miss: topic goes back to revision quietly, segments with wrong answers go to Recommended.
Done when: tests cover pass, fail, and re-check pass and miss; the re-check appears correctly when the device date is moved forward.
```
