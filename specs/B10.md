# B10 Admin and teacher dashboard (second developer)

Source: ATLAS V1 Build Guide, Claude Code pack tab, section 4. Exported 24 November 2026 in session S00.

```text
Read CLAUDE.md. This is step B10: the web dashboard, built with Expo web export in app/admin/. Plan first.
Admin can:
1. See flags by kind (stalled, borderline, safeguarding), newest first. Safeguarding flags are pinned at the top in their own section.
2. For a stalled flag: mark "content fix needed" or "human help suggested" and add a note.
3. For a borderline mark: see the question, scheme, pupil answer and AI notes; approve or change the mark.
4. See a pupil progress table: segments complete, moved on, tries, exam score, mastery.
5. See stall counts per segment.
6. Create classes and pupils, print code sheets, set consent dates.
Teacher can: see the progress table for their own class only. Read-only.
Done when: Bright clears a flag and approves a borderline mark from a laptop, and a teacher account cannot see another class.
```
