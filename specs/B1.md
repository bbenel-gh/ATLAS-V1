# B1 Data model and content import

Source: ATLAS V1 Build Guide, Claude Code pack tab, section 4. Exported 24 November 2026 in session S00.

```text
Read CLAUDE.md and the data model table I will paste below. This is step B1. Plan first.
Tasks:
1. Write Supabase migrations for every table in the data model, with foreign keys and sensible indexes.
2. Write Row Level Security policies: pupils read and write only their own rows; teachers read rows for pupils in their class; admins read and write everything. Content tables are readable by any signed-in user and writable only by admins.
3. Write src/data/contentSchema.ts: a zod schema for content/materials.json covering topic, segments, video versions, check items, worked examples, exam papers and re-check items.
   Each video version also has posterUrl, captionsUrl, boardColour (hex like #F6F0E6) and durationSeconds.
4. Write scripts/importContent.ts that validates content/materials.json and upserts it into Supabase using the service role key from a local .env (never shipped in the app).
5. Create content/materials.json with draft placeholder content for the overview and segments 1A to 1E so the app has something to show.
6. Add a temporary screen that lists the segments of the Materials topic.
Done when: one command imports the content; the screen lists 1A to 1E; a pupil account cannot read another pupil's attempts (prove it with a test query).
```
